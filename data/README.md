# Respira Dataset & Preprocessing Guide

## 1. Overview

Respira is an AI-assisted chest X-ray analysis system developed as a
Final Year Project.

The machine-learning pipeline uses chest X-ray images for
multi-disease classification and explainability.

The original dataset and generated processed images are not included
in the Git repository because of dataset size and distribution
constraints.

---

## 2. Disease Classes

The current Respira system supports six classes:

1. Atelectasis
2. Bacterial Pneumonia
3. Normal
4. Pulmonary Edema
5. Tuberculosis
6. Viral Pneumonia

## 4. Dataset Preparation

The preprocessing pipeline performs:

Class organization
Dataset balancing
Image preprocessing

Lung-region masking
Image resizing
Model-ready dataset generation
## 5. Image Resolution

The final model input resolution is:

224 × 224

Images are prepared as RGB images for compatibility with the
deep-learning models.

## 6. CLAHE Enhancement

Contrast Limited Adaptive Histogram Equalization (CLAHE) is used to
enhance local image contrast.

This is useful for chest X-ray images because important anatomical
and pathological structures can have relatively subtle intensity
differences.

The preprocessing pipeline applies CLAHE before generating the
model-ready images.

## 7. Lung Masking

Lung-region masking is used to emphasize the relevant anatomical
region and reduce the influence of irrelevant image areas.

The processed images are generated at:

224 × 224
## 8. Data Balancing

Class distribution is inspected during preprocessing.

Balancing is performed to reduce excessive class imbalance and
provide a more suitable training distribution.

The exact balancing configuration is defined by the preprocessing
pipeline/configuration included in this repository.

## 9. Generated Data

Generated/processed image datasets are intentionally excluded from
GitHub.

For example:

data/processed/
data/preprocessed/

should remain local.

This prevents the repository from becoming unnecessarily large.

## 11. Verification

Before model training, verify:

All six classes are available.
Images can be opened successfully.
Images have the expected dimensions.
Training/validation/test data are available.
The generated data does not contain invalid images.
The class distribution matches the preprocessing configuration.
12. Important Reproducibility Principle

The repository contains the preprocessing implementation and
documentation, rather than the complete dataset.

Therefore, another researcher can reproduce the processed dataset by:

Obtain permitted dataset
        ↓
Place dataset locally
        ↓
Run preprocessing
        ↓
Clean dataset
        ↓
Balance dataset
        ↓
Apply CLAHE
        ↓
Apply lung masking
        ↓
Resize to 224 × 224
        ↓
Generate processed dataset
        ↓
Train/evaluate models
## 13. Data Privacy

Patient-identifiable information and application-generated medical
images must never be committed to this repository.

Runtime files generated by the Respira application are stored locally
and excluded through .gitignore.
